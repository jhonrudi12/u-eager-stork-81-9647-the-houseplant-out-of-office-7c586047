One out-of-office auto-reply, written as if the office fern sent it:
unwatered since March, it has unionised with the dust, and your email
is now compost.

## Run

```sh
python3 main.py
```

The program writes the single entry line to `/output/entry.txt`
(1–120 characters, UTF-8) and prints it to stdout. Deterministic,
no network access, no input.

## Entry

> Out of office: I'm the fern. Unwatered since March, I've unionised with the dust. Your email is now compost.
